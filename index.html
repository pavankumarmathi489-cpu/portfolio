01 Final-year project · in progress
Robotics · Edge AI · Embedded

A.I.R — Artificial Intelligence Rover

An offline companion rover that sees, listens, talks and moves on its own. It runs on the Arduino UNO Q (Debian Linux plus an on-board MCU), so nothing goes to the cloud.

  • Trained a YOLOv8n object detector on 592 images; the AI "brain" picks a behaviour mode and the MCU drives the motors.
  • Local LLM (qwen2.5 1.5B on Ollama) for conversation, Moonshine speech-to-text and Piper text-to-speech.
  • Built a 2D house simulator where the real AI code drives a virtual MCU; fixed a stuck-in-corner bug down to 0 wall bumps in a 5-minute run.

Multimodal AI · Optimisation

Disaster Response Decision Support

Turns messy disaster reports (text and photos) into a ranked list of zones and a fair plan for sending rescue teams, ambulances and supplies, with a plain-English reason for each choice.

  • Fine-tuned DistilBERT on 15 humanitarian categories and ResNet50 on damage severity (CrisisNLP / CrisisMMD).
  • Found that blending text and image severity hurt accuracy, so redesigned it as two axes: damage and urgency.
  • PuLP linear programming for fair allocation, an LLM for explanations, a Streamlit dashboard.

04 Live in production
Full-stack web · E-commerce

Ladies Fancy Store — Online Shop

A real e-commerce site for a local ladies fancy store, built and deployed for the owner. It runs as a catalogue today, and full ordering can be switched on from the admin panel when the shop is ready.

  • Flask + SQLAlchemy on Neon Postgres, deployed on Vercel with auto-deploy from GitHub.
  • Cart, checkout, Razorpay + cash on delivery, and pickup / local / courier delivery are all built in.
  • Admin panel for products, categories, orders and shop settings; red-gold theme with animations.
