Portfolio admin

Edit every section of your portfolio and publish it to GitHub Pages.

  1. Open GitHub → new fine-grained token (signed in as your account).
  2. Repository access: Only select repositories → portfolio.
  3. Permissions: Repository permissions → Contents: Read and write. Generate, then copy it.
  4. Paste it below. It stays only in this browser and is sent only to GitHub.
